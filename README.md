# Anotador · descargas

Notas rápidas para Windows 10/11: pulsas un atajo, escribes y te olvidas. 100 % local, sin cuentas y sin nube.

Este repositorio sólo publica los **instaladores** y el archivo que usa la app para **actualizarse sola**. El código fuente es privado.

## Descargar

👉 **[Última versión](https://github.com/laskytt/anotador-releases/releases/latest)**

- `Anotador_x.y.z_x64-setup.exe`: recomendado. Se instala para tu usuario, sin permisos de administrador.
- `Anotador_x.y.z_x64_en-US.msi`: para instalaciones gestionadas.

Si Windows SmartScreen avisa de que la app no es conocida, pulsa **Más información → Ejecutar de todas formas**.

## Actualizaciones

Desde la versión 1.8.1, Anotador avisa cuando hay una versión nueva y se actualiza con un clic. Las actualizaciones van **firmadas**: la app sólo instala las publicadas por el autor.

Tus notas se guardan sólo en tu equipo (`%APPDATA%\Anotador`).
